# Cryptocurrency Fraud Network Analysis

## Project Overview

This project explores cryptocurrency fraud detection using graph analysis and community detection techniques on the Elliptic Bitcoin Dataset.
The research focuses on whether illicit transactions can be identified through transaction features, temporal behavior, and network structures.

## Dataset

This project uses the Elliptic Bitcoin Dataset.
Source:
https://www.kaggle.com/datasets/ellipticco/elliptic-data-set

## Research Questions

- Can illicit cryptocurrency transactions be identified through transaction features?
- Does temporal information explain illicit activity?
- Do illicit transactions form identifiable network structures?
- Can community detection reveal high-risk transaction clusters?

## Methods

- Temporal Analysis
- Feature Correlation Analysis
- Risk Propagation Analysis
- Network Structure Analysis
- Community Detection
- Community-based Risk Scoring

## Key Findings

- Transaction features alone show relatively weak correlation with illicit labels.
- Temporal fluctuations exist, but time alone does not strongly explain illicit activity.
- Illicit transactions tend to form local network clusters rather than isolated nodes.
- Community detection identifies several transaction groups with elevated illicit ratios.
- Unknown transactions connected to illicit clusters display significantly higher risk.
